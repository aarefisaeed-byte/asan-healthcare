# آسان · صورتحساب وکالتی حوزه درمان

وب‌اپ موبایل‌محور برای فعال‌سازی صورتحساب وکالتی پزشکان و مراکز درمانی. ارسال صورتحساب از طریق معتمد مالیاتی کیسان انجام می‌شود.

## اجرا

```bash
npm install        # نصب وابستگی‌ها
npm run dev        # اجرای نسخه توسعه روی http://localhost:5173
npm run build      # ساخت نسخه نهایی در پوشه dist (برای سرور)
npm start          # اجرای سرور (سایت + ارسال کد ورود) روی پورت 3000
```

## سرور و پنل پیامکی

سرور (`server/`) سایت ساخته‌شده را نمایش می‌دهد و کد ورود را از طریق پنل **پارس‌گرین** (سرویس `SendOtp`) پیامک می‌کند. کلید پنل فقط روی سرور و در فایل `.env` است و هیچ‌وقت به مرورگر نمی‌رسد.

```bash
cp .env.example .env   # ساخت فایل تنظیمات از روی نمونه
nano .env              # وارد کردن کلید پارس‌گرین و تنظیم SMS_PROVIDER=parsgreen
```

- `SMS_PROVIDER=console`: کد به‌جای پیامک در گزارش سرور چاپ می‌شود (برای آزمایش).
- هر کد ۲ دقیقه اعتبار دارد و حداکثر ۵ بار می‌شود امتحانش کرد.
- محدودیت ارسال: ۱۰ بار در ساعت برای هر IP و ۸ بار در روز برای هر شماره.
- بررسی سلامت: `GET /api/health`

### استعلام پرونده‌ها

بعد از ورود، سرور برای کد ملی کاربر شماره‌های اقتصادی `کدملی+0001` تا `کدملی+0010` را هم‌زمان از سرویس استعلام می‌پرسد و پرونده‌های پیدا‌شده را نمایش می‌دهد. آدرس سرویس فقط در `.env` با نام `INQUIRY_URL` است. اگر خالی باشد، پرونده‌های نمونه نمایش داده می‌شود.

- استعلام فقط برای کد ملی‌ای انجام می‌شود که کد پیامکی‌اش تأیید شده (کوکی ورود).
- سرویس استعلام فقط از IP داخل ایران جواب می‌دهد.

### پیامک دوم (اعطای مجوز به کیسان)

در مرحله مجوز، دسترسی ثابت «دریافت شناسه یکتای حافظه مالیاتی» با اعتبار یک‌ساله است. سرور یک رمز ۶ رقمی می‌سازد و متن کامل مجوز (شماره اقتصادی، تاریخ پایان، دسترسی و رمز) را با سرویس `SendSms` پارس‌گرین به همان موبایل ورود می‌فرستد.

### بیمارستان‌ها

فهرست ۱۷۳ بیمارستان و مرکز درمانی تهران در `src/data/hospitals.json` است و کاربر با نام یا محله در آن جست‌وجو می‌کند.

شاهکار و شناسه حافظه هنوز نمونه‌اند.

## ساختار

- `src/pages/Landing.tsx`: صفحه معرفی و فرم ورود
- `src/pages/FilesStep.tsx`, `PermissionStep.tsx`, `BuyersStep.tsx`, `SuccessStep.tsx`: مراحل فرایند
- `src/components/`: اجزای مشترک (لوگو، دکمه، پنجره، ورود کد تأیید)
- `src/lib/api.ts`: لایه سرویس‌ها. فعلاً داده نمونه است و بعداً به سرویس‌های واقعی وصل می‌شود.
- `src/lib/format.ts`: اعداد فارسی و اعتبارسنجی کد ملی و موبایل

## سناریوهای نمایشی (نسخه آزمایشی)

| ورودی | نتیجه |
| --- | --- |
| هر کد ملی معتبر و موبایل معتبر، هر کد ۶ رقمی (فقط پیش‌نمایش) | ورود موفق |
| کد تأیید `000000` (فقط پیش‌نمایش) | خطای «کد نادرست» |
| موبایلی که به `0000` ختم شود | خطای عدم تطابق شاهکار |
| موبایل `09129999999` | اختلال موقت سرویس |
| موبایلی که به `1111` ختم شود | پرونده‌ای پیدا نشد (حالت خالی) |
| پرونده «کلینیک تخصصی قلب نیایش» | هشدار شناسه حافظه فعال در کیسان و رفتن مستقیم به انتخاب نماینده |
| کد تأیید سازمان `000000` | خطای «کد نادرست» در مرحله مجوز |
| صبر تا پایان تایمر (۲ دقیقه) | کد منقضی و فعال شدن «ارسال مجدد» |
