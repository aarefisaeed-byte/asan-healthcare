# واسط استعلام (تونل SSH از داخل ایران)

سرویس استعلام شماره اقتصادی فقط به IPهای ایران جواب می‌دهد و سرور آسان در آمریکاست. برای همین یک کامپیوتر ویندوزی در شرکت یک تونل SSH به سرور باز می‌کند و سرور درخواست‌های استعلام را از داخل این تونل می‌فرستد.

```
سرور آسان (آمریکا) ──► 127.0.0.1:9101 ══ تونل SSH ══► کامپیوتر شرکت (ایران) ──► سرویس استعلام
```

- تونل از سمت شرکت باز می‌شود، پس IP ثابت یا تغییر فایروال شرکت لازم نیست.
- کاربر `tunnel` روی سرور فقط اجازه دارد همین یک تونل را روی `127.0.0.1:9101` باز کند: ترمینال ندارد و به فایل‌ها دسترسی ندارد.
- آدرس سرویس فقط در `.env` سرور (`INQUIRY_URL`) و در دستور تونل روی کامپیوتر شرکت است.

## تنظیم روی سرور

در `.env`:

```
INQUIRY_URL=<آدرس کامل سرویس>
INQUIRY_TUNNEL=127.0.0.1:9101
```

بررسی بدون نمایش آدرس:

```bash
sudo -u asan node /opt/asan/server/inquiry-check.mjs <شماره اقتصادی>
```

## اگر استعلام کار نکرد

1. روشن بودن کامپیوتر شرکت و اجرای تونل
2. روی سرور: `ss -tln | grep 9101` باید یک خط نشان دهد (تونل وصل است)
3. گزارش سرویس: `sudo journalctl -u asan -n 30 --no-pager`

## پیامک از داخل تونل (اختیاری)

اگر پنل پیامکی به سرور جواب ندهد، می‌شود درخواست‌های پیامک را هم از همین تونل فرستاد:

- در دستور تونل یک مسیر دوم اضافه می‌شود: `-R 127.0.0.1:9102:sms.parsgreen.ir:443`
- در `.env` سرور: `PARSGREEN_TUNNEL=127.0.0.1:9102`
- کلید تونل در `authorized_keys` باید اجازه پورت 9102 را هم داشته باشد (`permitlisten="127.0.0.1:9102"`)

`GET /api/health` در این حالت `"sms":"parsgreen via tunnel"` را نشان می‌دهد.
